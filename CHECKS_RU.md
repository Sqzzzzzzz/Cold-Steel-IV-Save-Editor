# Проверки

Актуальные результаты, среда и ограничения версии **0.1.2-preview** находятся в [docs/VALIDATION.md](docs/VALIDATION.md).

Самостоятельный запуск на Windows:

```powershell
.\Check_CS4.bat
```

При наличии эталонного сохранения задайте переменную `CS4_REFERENCE_SAVE`. Без неё один необязательный тест пропускается. Пользовательские сохранения не добавляйте в Git.
