## Русский

- В редакторе исправлена загрузка сохранений **«Новой игры+» (NG+)** и **Clear Data** для Cold Steel IV (NISA PC). При редактировании инвентаря данные переноса сохраняются.
- «Последнее сохранение» теперь находит автосейвы. Для U-материала поддерживаются стопки до 999 единиц.

Распакуйте Windows ZIP и запустите `CS4_Inventory_Editor.exe`. Перед правками сделайте резервную копию сохранения. Контрольная сумма ZIP указана в `SHA256SUMS.txt`.

## English

- Fixed an issue that prevented the editor from opening **New Game+ (NG+)** saves and **Clear Data** for the NISA PC version of Cold Steel IV. Inventory edits preserve carryover data.
- **Latest save** now finds autosaves. U-Material stacks are supported up to 999.

Extract the Windows ZIP and run `CS4_Inventory_Editor.exe`. Back up your save before editing. The ZIP checksum is in `SHA256SUMS.txt`.
