## Overview

The first stable release of **Cold Steel IV Inventory Editor**, a native Windows application for the NISA PC edition of *The Legend of Heroes: Trails of Cold Steel IV*.

The established Crimson Steel interface, controls and artwork are preserved. The project owner has confirmed that an edited save loads in the game and that the edited items are correct.

## Features

- Browse the installed base-game/DLC item catalog and your inventory.
- Search names, IDs and descriptions; filter categories, sources, ownership and favorites.
- Set quantities from 0 to 99, add/remove items and edit multiple selections.
- Review changes, undo/reset, compare saves and export CSV.
- Save separate copies or overwrite with a verified backup and external-change protection.
- English/Russian interface and separate localized catalog text.
- Native CS4 artwork for all 62 normal/EX master-quartz entries.

## Improvements

- Reuse unchanged table cells and category nodes instead of recreating them.
- Share icon resources and cache localized search text with explicit invalidation.
- Local comparison on 1,792 catalog entries and 900 inventory records measured about 4.6× faster unchanged refreshes and 1.8× faster search/sorting. These are scenario-specific measurements, not guarantees for every PC.
- Add a checked Windows build, executable version metadata, an explicit distribution allowlist and automated tag releases.

## Bug Fixes

- Restore painting and signal states if table updates fail.
- Avoid duplicate refreshes when switching mutually exclusive ownership filters.
- Release temporary change-review dialogs and quantity menus after closing them.
- Cancel deferred startup loading when its window is destroyed, avoiding a confirmed Qt/Python shutdown crash.
- Reject malformed character metadata in JSON catalogs before it can crash icon lookup.
- Include the earlier fixes for empty master-quartz icons and incomplete English catalogs.

## Installation

1. Download `Cold_Steel_IV_Inventory_Editor_v1.0.0_Windows_x64.zip` and `SHA256SUMS.txt` below.
2. Verify the archive checksum, then extract the entire ZIP.
3. Run `CS4_Inventory_Editor.exe`. No Python installation is required.
4. Select the game folder, open a compatible save and review your edits before saving a copy.

## Requirements

- 64-bit Windows 10/11.
- Your own installed NISA PC edition of Trails of Cold Steel IV for its item tables.
- Uncompressed GameData (3, 2) saves, exactly 1,463,976 bytes.

Console/CLE save formats are unsupported. No game tables, personal saves or external extraction tools are required in the ZIP.

## Important Notes

- **Back up saves outside the game directory and close the game before editing.** Use a separate copy first.
- The editor changes inventory items, not story flags or character statistics.
- Some non-master families retain shared CS3 category artwork; translations depend on locally available tables.
- If a localization patch replaced the English table, import an original `t_item_en.tbl` through Tools.
- The application is unsigned. Verify the source and checksum before accepting any Windows publisher/reputation prompt.
- Settings remain in `%APPDATA%\CS4InventoryEditor_BETA` to preserve preview profiles.
- Local Windows checks and automated Windows builds cover the supported workflow; compatibility with every mod, game revision or long-running session is not guaranteed.
