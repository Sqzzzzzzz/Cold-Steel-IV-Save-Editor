## Русский

Редактор инвентаря **Trails of Cold Steel IV — NISA PC** с интерфейсом RU/EN.

- Количество 0–99, массовые правки, поиск и фильтры.
- Отмена изменений, резервные копии и игровые иконки мастер-кварцев.
- В v1.0.0 ускорен интерфейс без изменения дизайна, исправлены ошибки и утечки памяти.

**Запуск:** скачайте Windows ZIP ниже, распакуйте и запустите `CS4_Inventory_Editor.exe`. Python не требуется.

**Требования:** Windows 10/11 x64 и установленная NISA PC-версия игры. Консольные/CLE-сохранения не поддерживаются.

**Важно:** закройте игру и сделайте резервную копию сохранений. EXE не подписан сертификатом.

## English

An inventory editor for **Trails of Cold Steel IV — NISA PC**, with English and Russian UI.

- Quantities from 0 to 99, batch edits, search and filters.
- Undo, backups and native master-quartz artwork.
- v1.0.0 improves UI performance without changing the design, and fixes bugs and memory leaks.

**Run:** download the Windows ZIP below, extract it and launch `CS4_Inventory_Editor.exe`. No Python installation required.

**Requirements:** Windows 10/11 x64 and the installed NISA PC game. Console/CLE saves are unsupported.

**Important:** close the game and back up your saves first. The EXE is unsigned.
