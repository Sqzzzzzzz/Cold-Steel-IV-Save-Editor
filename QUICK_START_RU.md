# Cold Steel IV Inventory Editor — Краткая инструкция

Русский · English: QUICK_START.md

1. Распакуйте весь ZIP и запустите `CS4_Inventory_Editor.exe`. Python не требуется.
2. Закройте игру и сделайте резервную копию сохранений вне игровой папки.
3. Выберите корень установки NISA PC с каталогом `data` или используйте автоматический поиск.
4. Откройте подходящий `saveXXX.dat`, выберите предмет, введите количество и нажмите **«Применить количество»**.
5. Просмотрите правки и сначала выберите **«Сохранить копию…»**.
6. При необходимости поместите копию в игровую папку с именем вида `saveXXX.dat`. Оригинальную резервную копию сохраните отдельно.

Нужны Windows 10/11 x64 и собственная установленная Trails of Cold Steel IV — NISA PC. Поддерживается несжатый GameData (3, 2) размером 1 463 976 байт. Консольные/CLE-форматы не поддерживаются. Игровые таблицы и личные сохранения не включены.

Обычная папка сохранений: `%USERPROFILE%\Saved Games\FALCOM\ed8_psv4`.
Настройки и кэш: `%APPDATA%\CS4InventoryEditor_BETA` — прежнее имя сохранено для совместимости.

Язык RU/EN переключается сверху. Если русификатор заменил английскую таблицу, импортируйте оригинальный `t_item_en.tbl` через **«Инструменты → Импорт английского каталога»**.

EXE не подписан сертификатом. Сравните SHA-256 архива с отдельным `SHA256SUMS.txt` из того же релиза. Не отключайте защиту ради непроверенного файла.
